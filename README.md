# MK ProcessSim

Simulador dinámico de un circuito cerrado de molienda de bolas y clasificación con hidrociclones.

## Funciones principales

- Balances dinámicos de sólidos y agua.
- Distribución granulométrica por clases y cálculo de P80.
- Molino, sumidero, bomba con control PI de nivel e hidrociclones.
- Modos de bomba automático y manual.
- Tendencias operacionales y exportación de granulometría.
- Alarmas visuales y detención por nivel alto del sumidero.

## Uso

Abre `index.html` en un navegador moderno. La aplicación funciona localmente y no requiere instalación de dependencias.

## Validación

Para ejecutar las pruebas con Node.js:

```bash
node tests.js
```

La documentación del modelo y el informe de validación se incluyen en el repositorio.
